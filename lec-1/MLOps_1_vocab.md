## Key Technical Terms

| Term | Meaning |
|---|---|
| **Drift** | Data or target changes after deployment, so the model gets worse |
| **Latency** | Time the model takes to give a prediction |
| **Schema** | Structure of the data (column names and types) |
| **Threshold** | A limit; above or below it, something happens |
| **MRR / NDCG** | Ranking metrics: how high the right results appear (0–1, higher is better) |
| **Technical debt** | Shortcuts that are easy today but painful to fix later |
| **Feedback loop** | Model predictions change the data the next model learns from |
| **Glue code** | Extra code written only to connect systems together |
